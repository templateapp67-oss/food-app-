# Asset provenance
Food illustrations and the Nexora bowl/steam icon are original SVG/code assets created for this project. No competitor imagery was scraped. Fonts use system fallbacks with optional Google Fonts DM Sans/Manrope; those fonts are OFL-licensed, fetched by the browser, not bundled in this package. Restaurant image uploads are subject to the operator obtaining appropriate rights.
Lucide icons: ISC. Gradle wrapper source/binary: Apache-2.0; retrieved from https://github.com/gradle/gradle/tree/v8.13.0.
